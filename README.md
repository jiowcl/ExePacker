# ExePacker  

A Simple PE File Packer.

This is a very simple program for verifying whether a PE file (EXE only) is packed; it is primarily designed to facilitate the binding of Interpreter/VM and Scripts (Source Code).

![GitHub](https://img.shields.io/github/license/jiowcl/ExePacker.svg)
![PureBasic](https://img.shields.io/badge/language-PureBasic-blue.svg)
![Status](https://img.shields.io/badge/Status-Experimental-orange)

## Environment  

- Windows 10/11 above (recommend)  
- PureBasic 6.0 above (recommend)  

## How to Build  

Building requires PureBasic Compiler and test under Windows 11.  
Module features require PureBasic 5.20 and above.

## Example  

```bash
ExePacker.exe target.exe
ExePacker.exe target.dll stub.bin
```
